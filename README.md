# DuelDraft — дуэли с драфтом улучшений (Paper 1.20.x)

## Как собрать
Нужны: **JDK 17 или новее** (https://adoptium.net) и интернет (Gradle сам скачает Paper API).

Открой терминал в папке проекта (где лежит `gradlew`) и выполни:

* Windows:  `gradlew.bat build`
* Linux / macOS:  `./gradlew build`   (если «permission denied» — `chmod +x gradlew`)

Готовый плагин: **`build/libs/DuelDraft.jar`** → кинь в папку `plugins/` сервера и перезапусти сервер.

Можно и через IntelliJ IDEA: File → Open → выбери папку → Gradle → Tasks → build → jar.

## Требования к серверу
**Paper 1.20.4** (собрано под этот API; 1.20.1–1.20.4 должны работать). Spigot не подойдёт — используются Paper-сообщения с кликабельными кнопками.

## Команды
| Команда | Что делает |
|---|---|
| `/duel <ник>` | Открывает меню: «Обычная дуэль» / «Необычная дуэль (драфт)». Забрать из меню ничего нельзя |
| `/duel accept`, `/duel deny` | Принять / отказаться (есть и кликабельные кнопки в чате) |
| `/duel leave` | Сдаться |
| `/duel stats` | Победы, поражения, винстрик |
| `/duel setarena 1` / `2` | (админ, право `duel.admin`) Встань на точку и выполни — задаёт точки появления бойцов |

Если арена не задана, бойцы ставятся друг напротив друга там, где стоит вызвавший.

## Как играется драфт
* Обратный отсчёт 5 сек → сразу первый драфт («ОБЫЧНОЕ УЛУЧШЕНИЕ»).
* Дальше по полоске босса: «СЛЕДУЮЩИЙ ДРАФТ: РЕДКОЕ → ЭПИЧЕСКОЕ → ЛЕГЕНДАРНОЕ», потом случайная редкость.
* Каждому дают 2 варианта, выбрать можно одно (на выбор 12 сек, иначе выбирается случайное).
* Всего **64 улучшения**: 17 обычных, 18 редких, 16 эпических, 13 легендарных (список — в `Upgrades.java`).
* Вещи, здоровье и позиция игроков сохраняются и возвращаются после боя (даже при краше — вернутся при входе).

Настройки (`plugins/DuelDraft/config.yml`): отсчёт, лимит времени, интервал драфта, время на выбор.

## Сборка на GitHub (без установки Java)
1. Создай репозиторий на github.com и загрузи в него **содержимое** папки проекта (вместе с папкой `.github`).
   Через терминал:
   ```
   git init
   git add .
   git commit -m "DuelDraft"
   git branch -M main
   git remote add origin https://github.com/ТВОЙ_НИК/DuelDraft.git
   git push -u origin main
   ```
2. Открой вкладку **Actions** — сборка запустится сама после каждого push (или нажми *Run workflow*).
3. Когда она станет зелёной, открой запуск и внизу в **Artifacts** скачай `DuelDraft` — внутри `DuelDraft.jar`.
4. Чтобы получить jar в разделе **Releases**, поставь тег: `git tag v1.0 && git push origin v1.0`.
